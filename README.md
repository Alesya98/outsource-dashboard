# Панель управления сотрудниками и проектами

**Employee & Project Dashboard**

Это компексное веб-приложение для управления ресурсами компании. Приложение позволяет менеджерам отслеживать сотрудников, проекты, распределять занятость, учитывать отпуска и видеть финансовые прогнозы по месяцам.

Приложение имеет интерфейс с двумя окнами просмотра (Проекты/Сотрудники), сворачиваемую боковую панель навигации, вычисления данных в реальном времени, а также расширенные возможности фильтрации и сортировки.

## Список функций

- Ведение базы сострудников(должность, зарплата)
- Управление проектами(бюджет)
- Распеределение сотрудников по проектам с коэфициентом 0,0-1,5
- Календарь отпусков с отслеживанием доступности
- Финансовые прогнозы: выручка, затраты, прибыль
- Ежемесячные снимки данных и копирование между месяцами
- Два режима просмотра: Проекты/Сотрудники 
- Сворачиваемая боковая панель навигации
- Фильтрация, сортировка

## Технологический стейк 

- HTML5 / CSS
- JavaScript
- localStorage (хранение данных)
- GitHub Pages
